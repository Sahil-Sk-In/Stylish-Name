## 🌟 Features

- **100% Offline & Zero Network Permission:** No `INTERNET` permission, no Firebase, no cloud login, and no activation locks.
- **Exact Salaam S2 Experience in Pure Kotlin:** ViewBinding + Material Components + RecyclerView + ConstraintLayout + DrawerLayout.
- **Home Studio & 12 Themes:** Animated concentric rings Home screen with Salaam Pink, Day Light, Night Dark, AMOLED Black, Crimson Black, Teal Black, and more.
- **Keyboard Studio (`EditorActivity`):** 20-button 2-row toolbar, Undo/Redo, Find & Replace, Font Size selector, A–Z Alphabet variants (114+ styles per letter), 18+ script blocks, Recent & Saved tabs.
- **Crunch Generator:** Transform any name with 25+ keyboard fonts, 100+ Intro/Outro decorations, and combining marks.
- **Style Book (12,236+ Items) & Make Name:** Instant search across 10 sections, Favorites, Recent history, Copy All, Share, and instant template framing.
- **Bundled Noto Fallback Fonts:** Renders complex Unicode symbols, combining marks, and scripts cleanly without missing glyph boxes.

## 📥 Download & Build

1. Visit the **[Releases](https://github.com/Sahil-Sk-In/Stylish-Name/releases)** page on GitHub.
2. Download `NameMaker-v2.0.0-Release-Signed.apk` and install on Android (API 24+).
3. Or open this folder in **Android Studio** and run `:app`.
